# 斯温·渲染比例（RenderScale）

国服卫月 API 15 **实验测试版**。只调整 3D 场景内部渲染比例，保留当前窗口和 HUD 尺寸。

例如输出为 **1980×1080**：75% → 1485×810；150% → 2970×1620；200% → 3960×2160。
插件读取实际输出尺寸，不会把 1980 改成 1920，也不设置桌面或窗口尺寸。

## 功能与边界

- 25–400% 自定义比例、常用预设、目标尺寸与实际 3D 尺寸分开显示。
- 15 秒预览，必须确认保留；未确认、窗口尺寸改变或实际尺寸持续不符时恢复。
- 每次加载默认关闭，只保存偏好比例。命令 `/swr off` 停止覆盖。
- 限制每边 64–8192、最多 33,554,432 像素，拒绝 NaN/无穷/无效尺寸。
- 当前只允许游戏已选择 **AMD FSR** 时启用；不会自行切换 DLSS。
- 固定比例需要暂时接管运行中的动态分辨率参数，关闭时恢复；不写游戏配置文件或调用画质设置保存接口。
- 提高比例会增加像素处理量、显存压力；不会增加纹理本身的细节。截图文件仍采用游戏输出尺寸。
- 首版仅接受已离线核对的国服 `2026.09.15.0000.0000` 游戏程序和配套结构库；更新后需重新核对。

## 当前验证状态

已进行本机构建、比例/预览状态测试及国服程序静态匹配。**尚未完成游戏内测试**，不能据此保证高比例画面、HUD 点击、GPose、切图、卸载恢复或 ReShade 兼容性。
这是独立测试包，不应在未经验收时作为稳定版向全部仓库用户推送。

## 本地安装与首测

1. 将 `RenderScale.zip` 解压至固定目录。
2. 在卫月设置的开发插件位置添加 `RenderScale.dll`，加载插件。
3. 先确认游戏使用 FSR，停用其他渲染比例插件。
4. 输入 `/swr`，先预览 75%，核对实际尺寸、画面及 HUD 点击，再测试 125%、150%。
5. 画面正常时确认保留；不操作会在 15 秒后请求恢复。`/swr off` 随时停止覆盖。

命令：`/swr` 打开；`/swr 150` 预览 150%；`/swr keep` 确认；`/swr off` 恢复。
画面冻结时预览计时无法强制修复 GPU/游戏崩溃；下次加载仍保持关闭。

## 构建

需要 .NET 10 SDK 和国服 API 15 开发库：

```powershell
./scripts/build.ps1 -DalamudHome '你的 XIVLauncherCN/addon/Hooks/dev 目录'
```

测试：`dotnet run --project tests/RenderScale.Tests -c Release`。
游戏二进制核对：安装 `pefile` 后运行 `py scripts/audit-signatures.py --game '游戏目录/game/ffxiv_dx11.exe'`。
该检查仅读取磁盘程序，不启动、注入或修改游戏。

## 来源

本版只引入场景缩放后端，移除了原项目的显示分辨率、窗口、光标和 HUD 调整入口。
