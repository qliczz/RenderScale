# 0.2.0.0 验证记录

日期：2026-09-27。目标：国服卫月 API 15。

## 已完成

- .NET 10 / API 15 本机构建：0 错误、0 警告。
- 49 项断言：1980×1080 比例计算、四舍五入、无效数值、显存预算对应的像素数上限、预览超时、实际尺寸确认、确认后失效、窗口改变、停止状态。
- 国服 `2026.09.15.0000.0000` 的 15 组签名/相对目标检查通过（见 `signature-audit.json`）。其中任务入口模板可有多个匹配，按管理器和目标函数筛选；运行中仍由任务表确定实例。
- ZIP 使用明确的依赖允许列表，不包含游戏程序、卫月主程序集、账户配置或本机日志。
- 插件不调用窗口设置、桌面设置、HUD 配置或游戏设置写入接口；只引入场景缩放模块。
- FSR 高于 100% 使用增大的场景渲染目标；DLSS 仅允许 25–100%，不进行 FSR 纹理重建。界面读取场景实际尺寸，而不是以输入值推算“已生效”。

## DLSS 改动与边界

- 检查游戏已选择 DLSS、游戏后端对象存在及 DLL 的 D3D11 EvaluateFeature 导出可观察；不将这些前置条件称为“DLSS 已生效”。
- Win64 四参数 ABI 与成功码 1 按 NVIDIA 官方头文件核对。加载时只引用已加载模块，卸载时先移除渲染线程钩子，再释放模块引用；不主动加载或替换 DLL。
- DLSS 的继承 FSR 钩子全部直通，运行参数覆盖之外，不进行 mip/blit 修正或 RTM 单独销毁/创建。
- 追加 19 项断言：DLSS 比例边界、预览宽限期、连续成功、失败返回码、调用停止、上次预览尚未返回的调用、未启用时调用与停止状态。
- 调用检测仅证明观察到本次预览的 DLL 调用成功，不能证明完整图像、正确 NGX 输入/输出资源尺寸或 DLAA 已启用。
- 高于 100% 的 DLSS 资源生命周期与最终缩小尚未实现；原先“上下均可调”的完整 DLSS 目标仍未完成。

## 未完成

游戏内运行、视觉对照、停止/卸载恢复、切图/GPose、ReShade 和 GPU 稳定性测试均待执行，见 `ACCEPTANCE.md`。
签名匹配只证明能定位预期代码，不能证明 GPU 输出正确或不会崩溃。

## 范围说明

为了固定比例，活动期间接管动态分辨率相关运行参数。正常停止恢复启用前的缩放、动态开关和缩放器；若用户修改相关保存设置，则采用用户的新设置。
不保存“启用”状态；如果游戏发生异常，重启并加载插件仍默认关闭。
只保存比例偏好，不写游戏配置。实际持久化配置是否完全不变仍需游戏内前后对照确认。
